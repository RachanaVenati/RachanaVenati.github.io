# Rachana Venati Portfolio

A responsive, single-page portfolio prepared for GitHub Pages.

## Files

- `index.html` - complete website with inline CSS and JavaScript
- `assets/Rachana_Venati_Resume.pdf` - downloadable résumé

## Publish with GitHub Pages

1. Create a repository named `RachanaVenati.github.io` under the `RachanaVenati` GitHub account.
2. Upload the contents of this folder to the root of the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. The site will be available at `https://rachanavenati.github.io/` after deployment completes.

## Quick edits

The design is contained in one `index.html` file. Search for the relevant heading or text to update content. Theme colors are controlled by the CSS variables near the top of the file.

For privacy, the public page intentionally omits the street address and phone number included in the source résumé.
