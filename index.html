01 / Retrieval-Augmented Generation

BUW at TREC 2024 — RAG

A complete retrieval-and-generation system for the TREC 2024 RAG track over the MS MARCO Segment v2.1 collection.

How the system works

Problem. Retrieve relevant evidence for 301 TREC RAG queries and generate grounded answers with traceable citations.

Retrieval. Pyserini/Lucene BM25 first retrieves the top 100 segments. Those candidates are then indexed in Weaviate and refined to the top 20 with MiniLM embeddings using either hybrid search or semantic Near Text search.

Generation. Llama 3 receives the original query plus the top retrieved segments. Prompt variants were tested to reduce unsupported content and make answers more concise.

Citations. Instead of relying on the LLM to place citations correctly, generated sentences are embedded and matched back to retrieved segments with cosine similarity, then supporting references are attached in post-processing.

Evaluation. The repository reports 0.752 precision and 0.860 average NDCG for the dense-on-sparse retrieval run using adapted TREC 2023 judgments as a development proxy.

02 / Multimodal Machine Learning

Nutri-Score Multimodal Sentiment Analysis

A three-class sentiment system for Instagram posts that predicts Positive, Neutral or Negative using both text and image information.

How the system works

Experiments. The project compares text-only, image-only, CLIP-based and image-text fusion approaches rather than treating multimodal learning as a single model choice.

Text branch. A RoBERTa sentiment model is fine-tuned on Instagram post text.

Image branch. A Vision Transformer processes post images, while a separate CLIP experiment explores joint visual-language representations.

Fusion. Learned text and image representations are combined in a dedicated fusion model for final sentiment classification.

Serving & reproducibility. The repository is structured as an installable Python package with CLI commands for splitting data, training each branch, evaluating predictions, and launching a FastAPI endpoint that accepts post text plus an image.

04 / Classical Computer Vision

Crack Detection

A MATLAB pipeline for detecting and structurally analysing cracks in wall-surface images without relying on deep learning.

How the system works

Pre-processing. Images are prepared, split and augmented to improve robustness across different surface conditions.

Segmentation. Intensity thresholding and morphological operations create binary crack masks, followed by connected-component analysis to remove noise and isolate crack regions.

Classification. Handcrafted region-level features are extracted and used with an SVM to distinguish crack from non-crack regions.

Structural analytics. Segmented cracks are thinned into skeletons so the pipeline can estimate crack length and inspect branching behaviour.

Evaluation. The code includes segmentation evaluation such as Intersection-over-Union and is designed as a lightweight classical alternative for limited-data or limited-compute settings.
